# Plano de Testes

## Testes iniciais

- Validar login.
- Validar cadastro de produtos.
- Impedir cadastro de produto sem nome.
- Impedir abertura de mesa ocupada.
- Validar inclusão de produtos na comanda.
- Validar cálculo de valores.
- Impedir fechamento com pagamento inválido.
- Validar liberação da mesa após fechamento.

## Tipos de testes

- Testes unitários.
- Testes de integração.
- Testes de API.
- Testes de interface.
