# Regras de Negócio

- RN001: Uma mesa não poderá possuir
  duas comandas abertas simultaneamente.

- RN002: Uma comanda poderá possuir
  vários pedidos.

- RN003: Um pedido poderá possuir
  vários itens.

- RN004: Produtos inativos não poderão
  ser adicionados aos pedidos.

- RN005: O preço deverá ser registrado
  no momento da venda.

- RN006: Somente usuários autorizados
  poderão cancelar pedidos.

- RN007: Comandas fechadas não poderão
  receber novos pedidos.

- RN008: A mesa será liberada após
  o fechamento da comanda.

- RN009: Operações importantes deverão
  possuir registro de auditoria.

- RN010: O fechamento deverá utilizar
  transação no banco de dados.
