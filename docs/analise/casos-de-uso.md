## UC001 - Realizar Login

Ator: Funcionário.

Fluxo:
1. Acessar a tela de login.
2. Informar e-mail e senha.
3. O sistema valida as credenciais.
4. O sistema permite o acesso conforme
   o perfil do funcionário.

## UC002 - Cadastrar Produto

Ator: Administrador ou gerente.

Fluxo:
1. Acessar produtos.
2. Clicar em cadastrar.
3. Informar nome, categoria e preço.
4. Salvar o cadastro.
5. O sistema confirma a operação.

## UC003 - Abrir Comanda

Ator: Garçom.

Fluxo:
1. Acessar mesas.
2. Selecionar uma mesa disponível.
3. Solicitar abertura da comanda.
4. O sistema registra a operação.
5. A mesa passa para ocupada.

## UC004 - Fechar Comanda

Ator: Caixa.

Fluxo:
1. Selecionar comanda aberta.
2. Conferir os pedidos.
3. Informar os pagamentos.
4. Confirmar fechamento.
5. O sistema registra o pagamento
   e libera a mesa.
