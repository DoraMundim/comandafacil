Arquitetura do Sistema

 Front-end
React + TypeScript + Vite.

Responsabilidades:
- Interface do usuário.
- Formulários.
- Navegação.
- Consumo da API.

 Back-end
Node.js + NestJS.

Responsabilidades:
- Regras de negócio.
- Autenticação.
- Autorização.
- Processamento de pedidos.
- Comunicação com banco de dados.

 Banco de dados
PostgreSQL.

 ORM
Prisma.

Comunicação
API REST utilizando JSON e HTTP.

 Versionamento
Git e GitHub.
